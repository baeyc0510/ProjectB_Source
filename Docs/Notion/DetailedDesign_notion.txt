# 1. 플레이어 시스템

## 1.1 캐릭터 기본 속성

| 속성 | 설명 | 기본값 |
|------|------|--------|
| 최대 체력 | 플레이어가 받을 수 있는 총 데미지량 | 100 |
| 현재 체력 | 현재 남은 체력 | 100 |
| 최대 Fervor | 마법 사용 자원 최대치 | 50 |
| 현재 Fervor | 현재 보유 Fervor | 0 |
| 이동 속도 | 초당 이동 픽셀 | 200 |
| 점프력 | 점프 시 초기 수직 속도 | -400 |
| 중력 | 초당 수직 가속도 | 980 |
| 최대 낙하 속도 | 수직 속도 제한 | 600 |

---

## 1.2 플레이어 상태 (State Machine)

### 1.2.1 상태 목록

| 상태 | 설명 | 전이 가능 상태 |
|------|------|----------------|
| IDLE | 정지 상태 | RUN, JUMP, ATTACK, SLIDE, FALL |
| RUN | 좌우 이동 중 | IDLE, JUMP, ATTACK, SLIDE, FALL |
| JUMP | 상승 중 | FALL, ATTACK_AIR, SLIDE_AIR |
| FALL | 하강 중 | IDLE, RUN, ATTACK_AIR, LAND |
| LAND | 착지 경직 | IDLE, RUN |
| ATTACK_1 | 지상 공격 1타 | ATTACK_2, IDLE, RUN |
| ATTACK_2 | 지상 공격 2타 | ATTACK_3, IDLE, RUN |
| ATTACK_3 | 지상 공격 3타 | IDLE, RUN |
| ATTACK_AIR | 공중 공격 | FALL |
| ATTACK_DOWN | 하강 찌르기 | LAND, IDLE |
| SLIDE | 지상 회피 | IDLE, RUN |
| PARRY | 패리 자세 | IDLE, PARRY_SUCCESS |
| PARRY_SUCCESS | 패리 성공 | ATTACK_COUNTER |
| ATTACK_COUNTER | 반격 공격 | IDLE |
| HIT | 피격 경직 | IDLE, FALL |
| DEATH | 사망 | NONE |
| EXECUTION | 처형 연출 | IDLE |

### 1.2.2 상태 전이 규칙

**IDLE 상태에서:**
- 좌/우 입력 → RUN
- 점프 입력 → JUMP
- 공격 입력 → ATTACK_1
- 회피 입력 → SLIDE
- 패리 입력 → PARRY
- 지면 없음 → FALL

**RUN 상태에서:**
- 입력 없음 → IDLE (감속 후)
- 점프 입력 → JUMP
- 공격 입력 → ATTACK_1 (이동 멈춤)
- 회피 입력 → SLIDE

**JUMP 상태에서:**
- 수직 속도 ≥ 0 → FALL
- 공격 입력 → ATTACK_AIR
- 아래 + 공격 → ATTACK_DOWN

**공격 상태에서:**
- 공격 애니메이션 특정 프레임 내 공격 입력 → 다음 콤보
- 애니메이션 종료 → IDLE

## 1.3 이동 시스템

### 1.3.1 수평 이동

**가속 방식:**
- 입력 방향으로 가속
- 가속도: 1200 픽셀/초²
- 최대 속도 도달 시 속도 유지
- 입력 해제 시 감속 (마찰)
- 감속도: 1800 픽셀/초²

**방향 전환:**
- 반대 방향 입력 시 즉시 감속 후 가속
- 스프라이트 좌우 반전 처리

### 1.3.2 점프

**가변 높이 점프:**
- 점프 버튼 누르는 동안 상승
- 버튼 해제 시 상승 속도 감소 (× 0.5)
- 최대 점프 높이: 약 120픽셀
- 최소 점프 높이: 약 40픽셀

**점프 허용 조건:**
- 지면에 서있을 때
- 코요테 타임: 지면 이탈 후 0.1초 내

**공중 제어:**
- 공중에서 좌우 이동 가능
- 공중 가속도는 지상의 80%

### 1.3.3 슬라이드 (회피)

**동작:**
- 입력 방향으로 빠르게 이동
- 이동 거리: 약 100픽셀
- 지속 시간: 0.3초

**무적 프레임:**
- 슬라이드 시작 후 0.05초 ~ 0.25초 구간 무적
- 총 무적 시간: 0.2초

**쿨다운:**
- 슬라이드 종료 후 0.3초간 재사용 불가

**특수 동작:**
- 슬라이드 중 적 통과 가능
- 낮은 천장 아래 통과 가능 (히트박스 축소)

## 1.4 플레이어 히트박스

### 1.4.1 충돌 박스 (Collision Box)

지형 충돌용 박스:
- 위치: 캐릭터 중심 기준
- 크기: 가로 24픽셀, 세로 48픽셀
- 슬라이드 시: 가로 24픽셀, 세로 24픽셀

### 1.4.2 피격 박스 (Hurt Box)

적 공격 판정용:
- 평상시: 가로 20픽셀, 세로 44픽셀
- 슬라이드 시: 비활성화 (무적)

# 2. 전투 시스템

## 2.1 기본 공격

### 2.1.1 지상 콤보

**3타 콤보 시스템:**

| 콤보 | 데미지 | 히트박스 범위 | 애니메이션 길이 | 캔슬 윈도우 |
|------|--------|---------------|-----------------|-------------|
| 1타 | 10 | 전방 60×40 픽셀 | 0.4초 | 0.15~0.35초 |
| 2타 | 12 | 전방 65×45 픽셀 | 0.45초 | 0.2~0.4초 |
| 3타 | 18 | 전방 80×50 픽셀 | 0.6초 | 없음 (종료) |

**캔슬 윈도우:**
- 지정된 시간 내 공격 입력 시 다음 콤보로 전이
- 윈도우 밖 입력은 무시 (버퍼링 없음)
- 콤보 중 이동 입력 가능 (약간 미끄러짐)

**히트 확인:**
- 각 공격의 활성 프레임에만 히트 판정
- 1타: 0.1~0.2초
- 2타: 0.1~0.22초
- 3타: 0.15~0.35초

### 2.1.2 공중 공격

| 공격 | 데미지 | 히트박스 범위 | 특성 |
|------|--------|---------------|------|
| 공중 횡베기 | 10 | 전방 55×40 픽셀 | 1회만 가능, 낙하 속도 유지 |
| 하강 찌르기 | 15 | 하단 30×60 픽셀 | 착지까지 지속, 적/지형 접촉 시 종료 |

**하강 찌르기 상세:**
- 아래 + 공격으로 발동
- 낙하 속도 증가 (× 1.5)
- 적 명중 시 튕겨오름 (수직 속도 -200)
- 착지 시 짧은 경직

### 2.1.3 에어 임펄스

**발동 조건:**
- 공중 공격이 적 또는 특정 오브젝트에 명중

**효과:**
- 수직 속도를 -250으로 설정 (위로 튕김)
- 공중 공격 횟수 초기화
- 연속 최대 4회 가능 (업그레이드 시)

---

## 2.2 패리 시스템

### 2.2.1 패리 동작

**입력:**
- 전용 패리 버튼 (기본: X키)

**타이밍:**
- 패리 자세 지속: 0.4초
- 성공 판정 윈도우: 자세 시작 후 0.05~0.2초 (0.15초간)

### 2.2.2 패리 성공 조건

**패리 가능 공격:**
- 적의 "약공격" 속성 공격만 패리 가능
- 강공격, 투사체는 패리 불가

**판정:**
- 패리 윈도우 중 적 약공격 히트박스와 접촉
- 거리 제한: 플레이어 전방 80픽셀 이내

### 2.2.3 패리 결과

**성공 시:**
- 적: 스턴 상태 1.5초
- 플레이어: PARRY_SUCCESS 상태
- 반격 공격 가능 (데미지 × 1.5)
- 화면 정지 효과 0.1초

**실패 시:**
- 패리 자세 종료 후 경직 0.2초
- 이 동안 피격 가능

---

## 2.3 처형 시스템

### 2.3.1 처형 조건

**적 스턴 상태:**
- 적 체력이 20% 이하일 때 공격 명중
- 패리 성공 후 (일부 적)
- 특정 보스 페이즈 전환

**표시:**
- 적 위에 처형 아이콘 표시
- 적이 붉게 깜빡임

### 2.3.2 처형 실행

**입력:**
- 스턴된 적 근처에서 상호작용 키 (기본: 위 방향키)

**연출:**
- 처형 애니메이션 재생 (적별로 다름)
- 이 동안 플레이어/적 모두 무적
- 다른 적 일시정지

### 2.3.3 처형 보상

| 보상 | 수치 |
|------|------|
| Fervor 회복 | 15 |
| 보너스 Tears | 기본 드롭의 50% 추가 |
| 체력 회복 | 없음 (기본) |

---

## 2.4 데미지 계산

### 2.4.1 플레이어 → 적```text
최종 데미지 = 기본 데미지 × 배율```text

**배율 적용:**
- 반격 공격: × 1.5
- 후방 공격: × 1.2
- 하강 찌르기: × 1.0

### 2.4.2 적 → 플레이어```text
최종 데미지 = 적 공격력 - 방어력
최소 데미지 = 1```text

**피격 후:**
- 무적 시간: 1.0초
- 넉백: 피격 반대 방향으로 80픽셀/초, 0.2초간
- 화면 흔들림: 강도 5, 지속 0.15초

# 3. 적 시스템

## 3.1 공통 속성

| 속성 | 설명 |
|------|------|
| 체력 | 적이 받을 수 있는 데미지 |
| 공격력 | 플레이어에게 주는 데미지 |
| 이동 속도 | 초당 이동 픽셀 |
| 시야 범위 | 플레이어 감지 거리 |
| 공격 범위 | 공격 발동 거리 |
| 드롭 Tears | 처치 시 드롭하는 재화 |

---

## 3.2 적 상태 머신

### 3.2.1 공통 상태

| 상태 | 설명 |
|------|------|
| IDLE | 정지, 주변 감시 |
| PATROL | 정해진 경로 순찰 |
| CHASE | 플레이어 추적 |
| ATTACK | 공격 동작 |
| HIT | 피격 경직 |
| STUN | 처형 가능 상태 |
| DEATH | 사망 |

### 3.2.2 AI 전이 규칙

**IDLE → PATROL:**
- 일정 시간(2~4초) 경과

**PATROL → CHASE:**
- 시야 범위 내 플레이어 감지
- 플레이어가 소리 발생 (근처에서 공격 등)

**CHASE → ATTACK:**
- 공격 범위 내 플레이어 진입

**CHASE → PATROL:**
- 추적 시간 초과 (5초)
- 플레이어가 시야 밖으로 이탈

**ANY → HIT:**
- 플레이어 공격 피격

**HIT → STUN:**
- 체력 20% 이하 상태에서 피격

## 3.3 적 유형 상세

### 3.3.1 Type A: 순찰병 (근접형)

**외형:** 갑옷 입은 병사

**속성:**

| 속성 | 값 |
|------|-----|
| 체력 | 30 |
| 공격력 | 15 |
| 이동 속도 | 80 |
| 시야 범위 | 150픽셀 |
| 공격 범위 | 50픽셀 |
| 드롭 Tears | 20 |

**행동 패턴:**

*순찰:*
- 좌우 일정 범위(200픽셀) 왕복
- 끝 지점에서 2초 대기 후 반환

*추적:*
- 플레이어 방향으로 이동
- 절벽/벽에서 정지

*공격:*
- 단일 횡베기
- 선딜레이: 0.3초
- 공격 지속: 0.3초
- 후딜레이: 0.5초
- **패리 가능**

---

### 3.3.2 Type B: 창병 (중거리형)

**외형:** 창을 든 병사

**속성:**

| 속성 | 값 |
|------|-----|
| 체력 | 25 |
| 공격력 | 12 |
| 이동 속도 | 60 |
| 시야 범위 | 200픽셀 |
| 공격 범위 | 90픽셀 |
| 드롭 Tears | 25 |

**행동 패턴:**

*순찰:*
- 좌우 일정 범위(150픽셀) 왕복
- 주기적으로 정지하여 경계

*추적:*
- 플레이어와 일정 거리 유지 (70픽셀)
- 너무 가까우면 후퇴

*공격:*
- 찌르기 공격
- 선딜레이: 0.4초 (창 당기는 모션)
- 공격 지속: 0.2초
- 후딜레이: 0.6초
- 공격 범위 길고 좁음 (100×20 픽셀)
- **패리 가능**

---

### 3.3.3 Type C: 돌진병 (돌격형)

**외형:** 방패 든 중장갑 병사

**속성:**

| 속성 | 값 |
|------|-----|
| 체력 | 45 |
| 공격력 | 20 |
| 이동 속도 | 50 (평시), 250 (돌진) |
| 시야 범위 | 180픽셀 |
| 공격 범위 | 120픽셀 |
| 드롭 Tears | 35 |

**행동 패턴:**

*순찰:*
- 느린 속도로 순찰
- 정지 시간 길음 (3초)

*추적:*
- 플레이어 발견 시 잠시 정지 (0.5초)
- 이후 돌진 시작

*공격 - 돌진:*
- 직선 돌진
- 선딜레이: 0.5초 (준비 자세)
- 돌진 거리: 최대 200픽셀
- 벽/절벽 충돌 시 0.8초 스턴
- 돌진 중 전면 공격 무효 (방패)
- 후면 피격 가능
- **패리 불가**

*벽 충돌 스턴:*
- 벽에 부딪히면 기절
- 이 동안 후면 공격 가능

## 3.4 적 피격 반응

### 3.4.1 일반 피격

- 피격 경직: 0.3초
- 넉백: 20픽셀
- 깜빡임: 0.1초간 흰색 플래시

### 3.4.2 연속 피격 저항

- 짧은 시간 내 연속 피격 시 경직 시간 감소
- 3회 이상 피격: 경직 0.1초
- 5회 이상: 슈퍼아머 발동 (경직 없음)

### 3.4.3 사망

- 사망 애니메이션 재생
- Tears 드롭
- 시체 페이드아웃 (2초)

## 4.2 Fervor (마나)

### 4.2.1 Fervor 획득

| 행동 | 획득량 |
|------|--------|
| 일반 공격 명중 | +3 |
| 콤보 3타 명중 | +5 |
| 처형 | +15 |
| 패리 성공 | +10 |

### 4.2.2 Fervor 소비

| 행동 | 소비량 |
|------|--------|
| Prayer 사용 | Prayer별 상이 (20~40) |

### 4.2.3 죄책감 페널티

- 사망 시 최대 Fervor 20% 감소
- 누적 가능 (최대 60% 감소)
- 죄책감 파편 회수 또는 정화로 복구

## 4.3 Tears of Atonement (재화)

### 4.3.1 획득 방법

| 출처 | 획득량 |
|------|--------|
| 일반 적 처치 | 15~35 |
| 보스 처치 | 500+ |
| 항아리 파괴 | 5~20 |
| 처형 보너스 | +50% |

### 4.3.2 사용처

| 용도 | 비용 예시 |
|------|-----------|
| 죄책감 정화 | 100~500 (누적에 따라) |
| Bile Flask 충전 | 200, 400, 600... (증가) |
| 능력 해금 | 500~2000 |

### 4.3.3 사망 시 처리

- 현재 보유 Tears 유지 (손실 없음)
- (원작과 달리 단순화)

## 4.4 Bile Flask (회복약)

### 4.4.1 기본 사양

| 항목 | 값 |
|------|-----|
| 초기 보유량 | 2개 |
| 최대 보유량 | 6개 (MVP 기준) |
| 회복량 | 30 HP |

### 4.4.2 사용

**입력:** 전용 키 (기본: C키)

**동작:**
- 사용 애니메이션: 0.5초
- 이 동안 이동 불가
- 🟡 중간에 취소 불가
- 공격받으면 사용 취소 (Flask 소모 안 함)

### 4.4.3 리필

- Prie Dieu (체크포인트)에서 자동 리필
- 전투 중 리필 불가

### 5.2.1 룸 구조

- 적 배치 데이터
- 오브젝트 배치 데이터

### 5.2.2 룸 전환

**전환 연출:**
- 페이드 아웃: 0.2초
- 로딩: 즉시 (데이터 적재)
- 페이드 인: 0.2초
- 플레이어 위치: 반대편 경계에 배치

### 6.1.2 HP 바

**위치:** 좌상단
**크기:** 120×12 픽셀

**표시:**
- 현재 HP / 최대 HP 비율로 채움
- 색상: 빨간색 (그라데이션)
- 데미지 시: 흰색 플래시 → 빨간색으로 감소
- 회복 시: 초록색 플래시 → 채워짐

### 6.1.3 Fervor 바

**위치:** HP 바 아래
**크기:** 80×8 픽셀

**표시:**
- 현재 Fervor / 최대 Fervor
- 색상: 파란색
- 죄책감 있을 시: 최대치 부분 회색 표시

### 6.1.4 Bile Flask 표시

**위치:** 좌상단 (Fervor 바 아래)
**형태:** 아이콘 × 개수

### 6.1.5 Tears 카운터

**위치:** 우상단
**형태:** 아이콘 + 숫자
**애니메이션:** 획득 시 숫자 롤업

# 7. 카메라 시스템

## 7.1 기본 동작

### 7.1.1 플레이어 추적

**타겟:** 플레이어 중심
**오프셋:** 플레이어 바라보는 방향으로 30픽셀 앞

**추적 방식:**
- 부드러운 추적 (Smooth Follow)
- 보간 계수: 0.1 (10% 씩 이동)
- 데드존: 중심 40×30 픽셀 (이 안에선 카메라 이동 없음)

### 7.1.2 경계 제한

- 카메라가 룸 경계 밖을 보여주지 않음
- 룸 크기가 화면보다 작으면 중앙 고정

---

## 7.2 특수 효과

### 7.2.1 화면 흔들림 (Screen Shake)

**트리거:**
- 플레이어 피격
- 강한 공격 명중
- 착지 (높은 곳에서)

**파라미터:**
- 강도: 1~10 (픽셀 단위 오프셋)
- 지속: 0.1~0.5초
- 감쇠: 시간에 따라 강도 감소

### 7.2.2 히트 스톱 (Hit Stop)

**트리거:**
- 공격 명중
- 패리 성공

**동작:**
- 게임 시간 일시 정지
- 지속: 0.03~0.1초
- 카메라/UI는 정상 동작

---

### 8.1.1 타이틀 화면```text
┌─────────────────────────────────┐

│         BLASPHEMOUS             │

### 8.1.2 게임 시작 시

1. 세이브 데이터 확인
2. 있으면: 마지막 Prie Dieu에서 시작
3. 없으면: 시작 지점에서 시작

---

## 8.2 사망 처리

### 8.2.1 사망 시퀀스

1. 플레이어 사망 애니메이션 (1초)
2. 화면 페이드 아웃 (0.5초)
3. "YOU DIED" 텍스트 표시 (1.5초)
4. 화면 페이드 인 (0.5초)
5. 마지막 Prie Dieu에서 부활

### 8.2.2 부활 시 상태

- 체력: 최대치
- Fervor: 0
- Bile Flask: 최대치
- 위치: 마지막 Prie Dieu
- 죄책감: +1 단계

---

## 8.3 세이브 시스템

### 8.3.1 저장 데이터

| 데이터 | 설명 |
|--------|------|
| 플레이어 스탯 | 최대 HP, 최대 Fervor, Flask 개수 |
| 현재 자원 | Tears, 죄책감 단계 |
| 진행 상황 | 활성화된 Prie Dieu, 처치한 보스 |
| 수집 아이템 | 획득한 아이템 목록 |

### 8.3.2 저장 시점

- Prie Dieu 사용 시 자동 저장
- 일시정지 메뉴에서 수동 저장 없음 (자동만)
