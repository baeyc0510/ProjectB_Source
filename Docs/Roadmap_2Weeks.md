# 블래스퍼머스1 WinAPI 모작 - 2주 개발 로드맵

## 프로젝트 개요
- **목표**: 블래스퍼머스1의 핵심 게임플레이를 WinAPI 기반으로 구현

- **리소스**: 원작 추출 리소스 활용

## 기술 스택

### 필수 라이브러리
- **WinAPI**: 윈도우, 입력, 기본 렌더링
- **GDI+**: 이미지 로딩, 알파 블렌딩

### 권장 라이브러리
- **FMOD/XAudio2**: 사운드 (선택)
- **nlohmann/json**: 데이터 파싱 (선택)

### 프로젝트 구조 (권장)
```
Blas/
├── Docs/              # 문서
├── Resources/         # 게임 리소스
│   ├── Sprites/
│   ├── Sounds/
│   └── Maps/
├── Source/
│   ├── Engine/        # 엔진 핵심
│   │   ├── Core/      # 게임루프, 윈도우
│   │   ├── Render/    # 렌더링
│   │   ├── Input/     # 입력
│   │   └── Sound/     # 사운드
│   ├── Game/          # 게임 로직
│   │   ├── Player/
│   │   ├── Enemy/
│   │   ├── Combat/
│   │   ├── Level/
│   │   └── UI/
│   └── Main.cpp
└── Blas.sln
```
