## 기술 스택

### 사용 중

- **WinAPI**: 윈도우, 입력, 기본 렌더링
- **GDI+**: 이미지 로딩, 알파 블렌딩
- **nlohmann/json**: 애니메이션 데이터 파싱

### 코드 컨벤션

- `Anim::` 네임스페이스로 애니메이션 키 관리 (AnimKeys.h)
- `constexpr`/`const`로 상수 정의
- 단일 사용 상수는 지역 변수로
- State/Tag 시스템으로 상태 관리
- 이벤트 기반 Ability 설계 (WaitEvent/TriggerEvent)
