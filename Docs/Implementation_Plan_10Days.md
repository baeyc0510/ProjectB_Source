## 계획 수립 기준

### 1. 완성도 우선 (Completion First)
- "작동하는 게임"이 최우선
- 플레이 가능한 루프: 시작 → 전투 → 사망 → 재시작
- 외부 시연 가능한 수준

### 2. 핵심 경험 우선 (Core Experience First)
- 블래스퍼머스의 핵심 재미 요소에 집중
- 묵직한 전투감, 패리의 쾌감
- 시각적 피드백 (UI, 이펙트)

### 3. 기술적 안정성 (Technical Stability)
- 버그 없는 안정적인 빌드
- 확장 가능한 구조 유지

## Plan A: 기능 완성형 (Feature-Complete)

**컨셉**: 설계 문서의 "권장(Should Have)" 기능까지 최대한 구현

### 일정

| 일차 | 작업 내용 | 산출물 |
|------|-----------|--------|
| Day 1 | HP 시스템 + 사망 처리 | 플레이어/적 HP, 사망 애니메이션 |
| Day 2 | UI/HUD 기본 | HP바, Flask 표시, Tears 카운터 |
| Day 3 | UI/HUD 고급 + 데미지 숫자 | Fervor바, 플로팅 데미지 |
| Day 4 | 적 AI 개선 | 순찰, 추적, 시야 범위 |
| Day 5 | 추가 적 타입 2종 | 창병(중거리), 돌진병 |
| Day 6 | 처형 시스템 + Bile Flask | 스턴 상태, 회복 시스템 |
| Day 7 | 체크포인트 + 부활 | Prie Dieu, 사망/부활 플로우 |
| Day 8 | 레벨 디자인 | 테스트 스테이지 완성 |
| Day 9 | 카메라 + 화면 효과 | 스무스 팔로우, 히트스톱, 화면 흔들림 |
| Day 10 | 통합 + 폴리싱 | 버그 수정, 밸런스 조정 |

### 장점
- 풍부한 게임플레이 경험
- 설계 문서와의 높은 일치도
- 포트폴리오로 강한 어필

### 단점
- 시간 압박 높음
- 버그 발생 가능성 높음
- 폴리싱 시간 부족 가능

### 리스크
- 일정 지연 시 미완성 기능 다수 발생
- 후반 버그 수정에 시간 소모

### 일정

| 일차 | 작업 내용 | 산출물 |

| Day 2 | UI/HUD | HP바, Flask 표시 (필수만) |
| Day 3 | 적 AI 개선 | 순찰, 추적, 공격 패턴 |

| Day 5 | Bile Flask + 회복 시스템 | 회복 아이템 사용 |
| Day 6 | 체크포인트 + 부활 플로우 | 사망 → 부활 완전 구현 |
| Day 7 | 레벨 디자인 | 테스트 스테이지 |

### 단점
- 처형 시스템 제외
- Fervor 시스템 제외
- 적 종류 제한 (2종)

### 리스크
- 낮음 (버퍼 시간 존재)

## Plan C: 핵심 집중형 (Core-Focused)

**컨셉**: 현재 구현된 전투 시스템 완성도 극대화 + 최소한의 게임 루프

### 일정

| 일차 | 작업 내용 | 산출물 |
|------|-----------|--------|
| Day 1 | HP 시스템 + 사망 | 기본 체력 시스템 |
| Day 2 | UI/HUD (HP만) | 최소한의 UI |
| Day 3 | 기존 전투 시스템 폴리싱 | 타격감 개선, 버그 수정 |
| Day 4 | 적 AI 개선 | 현재 적의 행동 다양화 |
| Day 5 | 카메라 + 화면 효과 | 히트스톱, 화면 흔들림 |
| Day 6 | 레벨 디자인 | 간단한 테스트 스테이지 |
| Day 7 | 사망/부활 플로우 | 게임 루프 완성 |
| Day 8 | 사운드 기본 | 타격음, BGM |
| Day 9 | 종합 폴리싱 | 연출 개선 |
| Day 10 | 최종 테스트 | 안정화 |

### 장점
- 높은 완성도와 안정성
- 전투 시스템의 깊이 있는 체험
- 폴리싱 시간 충분

### 단점
- 콘텐츠 양 부족
- 적 1종만 존재
- 회복/체크포인트 없음

### 리스크
- 게임플레이 단조로움
- 콘텐츠 부족으로 어필력 감소

## 권장 사항

### 추천: Plan B (균형형)

**이유:**
1. **현실적 일정**: 예상치 못한 버그/이슈에 대응 가능한 버퍼 존재
2. **완전한 게임 루프**: 시작 → 전투 → 사망 → 부활의 핵심 경험 제공
3. **시연 가능**: 외부에 보여줄 수 있는 완성된 데모
4. **확장 기반**: 이후 추가 기능 구현을 위한 안정적 토대

### Plan A 선택 시 주의사항
- 일정이 빡빡하므로 매일 목표 달성 필수
- Day 8 이후 새 기능 추가 자제
- 기능 축소 결정을 빠르게 내릴 준비

### Plan C 선택 시 고려사항
- 전투 경험의 품질이 매우 높아야 함
- 짧은 플레이 시간이지만 강렬한 인상 필요
- "기술 데모" 느낌이 될 수 있음
