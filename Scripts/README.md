# Map Editor

Blasphemous Clone 맵 에디터 도구

## 설치

```bash
pip install -r requirements.txt
```

## 실행

```bash
python map_editor.py
```

## 조작법

### 카메라
- **화살표 키**: 카메라 이동
- **Shift + 화살표**: 빠른 이동

### 레이어
- **1-9 키**: 레이어 선택
- **+ Layer**: 새 레이어 이미지 추가
- **- Layer**: 선택된 레이어 삭제
- **Layer Up/Down**: 레이어 순서 변경
- **Set Meta Image**: 선택된 레이어에 메타 이미지 설정
- **Parallax 슬라이더**: 선택된 레이어의 패럴랙스 값 조정

### 툴
- **Select**: 기본 선택 모드
- **Set Spawn**: 클릭한 위치를 플레이어 스폰으로 설정
- **Add CP**: 체크포인트 추가
- **Add Trans**: 씬 전환 트리거 추가 (드래그로 영역 지정)

### 기타
- **Meta Overlay**: 메타 이미지 오버레이 표시 토글
- **Grid**: 그리드 표시 토글
- **우클릭**: 체크포인트/트랜지션 삭제
- **ESC**: 현재 작업 취소

| 파랑 | (0,0,255) | 사다리 |

| 보라 | (128,0,128) | 늪 |
| 노랑 | (255,255,0) | 데미지 |
